# Security policy

The supported version line is **2.x**. Use the latest available patch release.

Report vulnerabilities privately using this repository's GitHub **Security → Report a
vulnerability** (private vulnerability reporting / Security Advisories). Include affected
versions, reproduction steps and impact. Do not disclose credentials or exploit details in
public issues. If private reporting is unavailable, ask the maintainers to enable it without
posting vulnerability details.

Scope includes the TeleLogin server, Telegram bot and shipped integration examples.
Misconfigured deployments are out of scope, including exposed internal endpoints, untrusted
cookie subdomains, public backends bypassing the proxy, and trusting arbitrary forwarded headers.
